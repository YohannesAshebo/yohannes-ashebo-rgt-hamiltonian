# Changelog

## 0.1.0 — 2026-11-20

- First prepared Apache 2.0 research release, credited to Yohannes Beyene Ashebo.
- Original radial v0.5 and current-dependent counterflow source preserved.
- Saved 256- and 512-cell s=90 states and original audit included.
- Independent energy, every-coordinate gradient and heat-power checks included.
- Direct source-tree auditing added for inspection and modification; the
  unchanged snapshot remains an explicit reproducibility option.
- Machine-readable citation, equations, dependency notices and known
  limitations supplied.
- Five-grid zero-integration manufactured-profile checks and a conservative
  saved-state radial comparison added. Integrated heat approaches a finite
  value with observed order near one on the tested families. New static
  1024/2048 profiles are not represented as evolved s=90 checkpoints.
- No new Hamiltonian, physical parameter fit, 1024-cell state, public DOI or
  external replication is introduced by this release preparation.
